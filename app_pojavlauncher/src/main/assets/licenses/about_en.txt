%s (Minecraft Java Launcher for Android), version %s<br>

Turtle Launcher is built on the <a href="https://github.com/AngelAuraMC/Amethyst-Android">Amethyst</a>
launcher core (Minecraft 26.x support, LWJGL 3.4.x, SDL3, runtime and renderer infrastructure),
which is in turn based on
<a href="https://github.com/PojavLauncherTeam/PojavLauncher">PojavLauncher</a> and
<a href="https://github.com/zhuowei/Boardwalk">Boardwalk</a> (JVM launcher by ZhuoweiZhang).<br><br>
